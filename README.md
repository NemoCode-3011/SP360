# SP360

A camera-brand landing-page concept built with HTML and CSS, using custom typography and image assets to present the product identity.

**Live website:** https://sp-360-delta.vercel.app/

## Built with

- HTML
- CSS
- Custom fonts and image assets

## Run locally

No package installation is required. Open `index.html` in a browser, or use a local static server to preview the page.

## Project scope

This repository contains a static frontend website concept. It does not include camera hardware integration or a backend service.
